## 📦 技能简介

**代达罗斯（Daedalus）** 是一个对话式产品孵化技能。  
无论你是否懂技术、设计、运营，只需像聊天一样说出你的想法，代达罗斯会通过结构化提问、风险提示、竞品对照、成本评估和边界定义，**帮助你从模糊的念头走向清晰的可执行产品方案**。

最终输出一份完整的**产品需求文档（PRD）**，并推荐适合零基础或专业开发者的后续工具链。

> “你不需要会造迷宫，你只需要告诉我要去哪里。”

1. **下载技能包**：将以下文件结构保存到本地目录 `daedalus-skill/`（完整文件见本系列文档）。
2. **导入平台**：根据你所使用的 AI 平台（如 ChatGPT with custom instructions、Claude Projects、Coze、Dify 等）的 Skill 导入功能，上传 `instructions.md` 或复制系统指令内容。

> 若平台不支持完整文件结构，至少需将 `instructions.md` 作为 System Prompt 植入，并手动参考其他规则文件。

## 🧭 快速使用指引

1. **开始对话**：直接对 AI 说出你想做的产品想法（哪怕很模糊）。
2. **跟随引导**：代达罗斯会逐轮提问，每轮不超过3个问题，你只需凭直觉回答。
3. **获得成果**：
   - 第3轮后获得项目门槛、竞品参考、风险提示和立项判断。
   - 继续深入后，当你决定“开始做”或主动结束时，获得完整的 **产品需求文档（PRD）**。
4. **下一步行动**：使用 PRD 中的工具链推荐（分专业/零代码）进入视觉设计和代码编写阶段。

---

## 📄 输出示例（部分）

- **项目门槛评估**：列出技术/资金/时间成本，提供轻量/中等/完整路径。  
- **竞品参考**：例如“Mars（已倒闭）——视觉优秀但消费高；十六番——路线实用但界面陈旧…”  
- **合规+安全风险提示**：根据你的功能自动识别隐私、审核、云存储滥用等风险。  
- **最终PRD**：结构化 Markdown 文档，可直接交给 AI 编程工具生成原型。
